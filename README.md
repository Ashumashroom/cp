## 🔢 Digit DP


Problems solved using **Digit Dynamic Programming**.


### Concepts Covered
- Tight vs Non-tight states
- Leading zero handling
- Memoization over digit position
- Counting numbers in a range


### Typical DP State

dp[pos][tight][state]



### Concepts Covered
- Two pointers
- Fixed and variable window
- Frequency counting


### Problems Included
- Longest subarray with given condition
- Minimum window substring
- Subarray sum problems
